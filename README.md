# mvp-projeto-ti

Projeto acadêmico de desenvolvimento de um MVP para a disciplina de Tecnologia da Informação.

## Objetivo do projeto

Desenvolver uma versão inicial de um produto mínimo viável (MVP), aplicando conceitos de planejamento, desenvolvimento e organização de software.

## Organização e controle de versão

O projeto utiliza o GitHub para armazenar os arquivos, registrar alterações por meio de commits e realizar revisões técnicas com Pull Requests.

## Etapas de desenvolvimento

- Planejamento e organização do projeto.
- Implementação das funcionalidades.
- Revisão técnica do código.
- Testes e validação das alterações.

## Status

Projeto acadêmico em desenvolvimento.
